# Audit-Readiness-Check
Free ISO/IEC 27001:2022 audit readiness self-assessment. Rate 47 requirements across clauses 4 to 10 and Annex A, then get a weighted score, ranked gaps and the evidence auditors ask for. Evidence only counts with a named reviewer and a review in the last 12 months. One HTML file. Runs in your browser. Nothing is uploaded.
