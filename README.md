# Audit Readiness Check

A free self-assessment for teams preparing for an ISO/IEC 27001:2022 audit.

Rate where each requirement stands today and get:

- A weighted readiness score
- A ranked list of gaps, with required documents first
- The evidence an auditor is likely to ask for on each item
- A copyable action list

## How it works

The tool covers 47 items across management system clauses 4 to 10 and a selection of Annex A controls. Rate each item as Not started, In progress, In place or Evidenced.

Evidence only counts as Evidenced when it has a named reviewer and a review date within the last 12 months. Otherwise the item scores as In place. This reflects a common audit finding: a record exists, but nobody can say who reviewed it or when.

## Using it

Open `index.html` in any browser. There is nothing to install.

The tool opens with example answers for a mid-sized software company. Select "Clear and start mine" to assess your own organisation.

## Privacy

Answers are stored in your browser only. Nothing is sent to a server.

## Limitations

This check supports preparation. It does not replace an audit by a certification body. The questions summarise the intent of the standard and are not its text. Your Statement of Applicability decides which Annex A controls apply to you.
