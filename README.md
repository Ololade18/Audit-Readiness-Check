# ISO 27001 Tools

Free, browser-based tools for teams preparing for an ISO/IEC 27001:2022 audit. Each tool is a single HTML file. Nothing is installed, uploaded or stored on a server.

## Tools

| Tool | What it does | Link |
|---|---|---|
| Audit Readiness Check | Rate 47 requirements and get a weighted score, ranked gaps and the evidence auditors ask for. Evidence only counts as Evidenced with a named reviewer and a review in the last 12 months. | [Open](https://ololade18.github.io/Audit-Readiness-Check/) |
| Statement of Applicability Builder | Decide which of the 93 Annex A controls apply, record the reason, status, owner and evidence, check for gaps and export to CSV. | [Open](https://ololade18.github.io/Audit-Readiness-Check/soa-builder.html) |

## Using them

Open either link in any browser. Each tool opens with example answers. Select "Clear and start mine" to work on your own organisation.

## Privacy

Answers are stored in your own browser only. Nothing is sent to a server.

## Limitations

These tools support preparation. They do not replace an audit by a certification body. Questions and control names are short summaries and are not the text of the standard. Your Statement of Applicability should reflect your own risk assessment and risk treatment plan.
